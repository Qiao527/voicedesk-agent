# Decisions

Store short, durable decisions here when they would otherwise be re-litigated in chat.

Good candidates:

- auth and business-scoping strategy
- Google token storage strategy
- whether to stay managed-service-first or add more SaaS features
- Vapi transfer implementation choices
- schema naming decisions that affect multiple surfaces

Suggested format:

- date
- decision
- context
- chosen path
- consequences

Keep each decision short. If it is not worth revisiting later, it probably does not need a file here.
